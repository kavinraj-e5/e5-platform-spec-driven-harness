# App library

Part of [app-development](../README.md).

`rf-fb-worker-core` is the Python library every app runs on: the poll loop, the AKST pull, the `TaskComplete` reply and the Citrix helpers. Its task contract comes from `task-sdk-python`. `app-sdk` (AppSDK, the function blocks) is built from `app-lib-scaffolding`. `non-rpa-worker-core` is the Java core for non-RPA app workers.
