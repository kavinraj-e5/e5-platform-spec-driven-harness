# App (runtime)

Part of [app-development](../README.md).

A running app is `fb-worker`: `rf-fb-base-image` + `rf-fb-worker-core` + a customer app's Robot Framework source, one image per app. `fb-worker-app-contract.md` says exactly what an app must supply. The customer app itself is not a platform deliverable.
