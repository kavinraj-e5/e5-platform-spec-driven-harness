# Workflow library

Part of [workflow-development](../README.md).

What a workflow developer builds with. `platform-core` is the SDK and the code of every workflow role. `wf-scaffolding` is the seed project for a new workflow. `variant-scaffolding` composes platform-core, AppSDK and the workflow jar into the variant image. A change here is a library release: it reaches production only when each variant bumps its pin. Versions: `../../dependencies.md`.
