# Workflow (runtime roles)

Part of [workflow-development](../README.md).

One variant image runs several roles, chosen at runtime by `WORKER_MODE`. These roles have no image of their own. Their code is in `platform-core` (see `../workflow-library/`). The in-namespace task queue `akst` is the same kind of role, documented under `communication/`.

## Members
